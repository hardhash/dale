### 2. The case for explanations

首先解释一下什么叫可解释性，如果我们想要解释一个模型的预测结果，如果是文本数据，需要给出人类可以理解的单词对模型预测结果的影响，所以展示给人类的应该是以单词为粒度的特征重要性，如果是图像数据，那么就是图块为粒度的图块重要性，都会给出一个定性的人类可以理解的解释，他们称之为可解释元素，例如文本中的单词和图像中的图块。

这个指标呢是不一定科学的，一味的去追求准确率可能会带来一些牺牲。这里存在一个trade-off，就是这个准确率不能直接衡量这个产品产生的价值，如果这个模型一味的追求准确率而用了一些错误的特征，牺牲用户体验的特征，例如诱导用户点击弹窗广告，那么用户点击了可能会增加算法的准确率，但是用户存在一个胁迫，劫持的过程，牺牲了用户体验，会影响用户留存。但是算法不知道，算法是死的，所以这个时候也要引入可解释性，不能一味看冰冷指标，而是要看脑回路。

![img_32.png](img_32.png)

接下来是lime的基本假设，第一条就是易于被理解，而且特征数量不能很多，因为不能一上来给人类看成千上万个特征，哪怕用的是线性模型这种非常简单的模型，也不能搞太多特征在里面，需要给人类一个抓手。

![img_33.png](img_33.png)

第二点就是训练原模型的特征可能难以理解，例如词向量，卷积放缩，这些训练原模型的特征可以难以理解，但是训练可解释模型必须易于理解。例如uni gram词袋模型，超像素分割后的图块存不存在等。对于外行，laymen，需要足够的简单直观。就好像我们在这里讲论文，可能有这方面工作经验的人一下就能明白你在说什么，但是如果没有从事过相关工作，就必须让他们也能理解，让他们足够舒服。be more comfortable，对于解释而言，让外行进入舒适区是一个非常重要的事。

![img_34.png](img_34.png)

这是第一条，必须易于理解。第二条，必须局部保真。就是可解释模型拟合出来直线必须和原模型的决策边界尽可能贴近，原模型认为重要的可解释模型也要认为重要。虽然在高维非线性空间里很难真正拟合出原模型行为，但是在局部领域里必须足够准，足够faithful，足够的local fidelity。局部的fidelity不一定全局fidelity，全局fidelity也不一定局部fidelity，就是局部重要的特征全局不一定重要，全局重要的特征局部也不一定重要，但从主观上，还是要尽可能做到局部保真。

![img_35.png](img_35.png)

实现了以上两点，就得到了一个model-agnostic，与模型无关的通用的机器学习模型可解释方法，虽然我们挑选出的可解释模型，例如决策树，逻辑回归，线性回归等，但是它得能应用于各种模型中，意思是你可以从这些可解释性好的模型随便挑一个去座位拟合你原始模型局部线性领域的可解释模型。因此你可以用它对现在一些非常好的sota算法，state-of-the-art算法，做可解释分析，甚至对现在不存在，未来才存在的算法做可解释性分析。

这是对单个预测结果的可解释性，如果是多个呢。我们可以用多个有代表性的单个预测结果来反应整个模型的可解释性，来实现global perspective，全局视角。用若干有代表性的单个样本来反应整个模型的可解释性。

### 3. Local Interpretable Model-agnostic Explanations

![img_36.png](img_36.png)

第三章就是lime算法的基本原理

![img_37.png](img_37.png)

那首先，要把原始的这个待测样本变成可解释特征，所以这里面有两种特征，一种是训练原模型的特征，一种是训练可解释模型的可解释特征。在文本上呢，可解释特征就是binary vector，unigram词袋模型，而不是使用非常复杂的word embedding，因为word embedding是训练原模型的非常不可解释的特征，而我们现在用binary vector，unigram词袋模型可解释特征来训练可解释模型，这些特征是人类可以理解的。如果是在图像域里，可解释特征就是很多图块出现或者不出现，保留原始像素还是抹去。原模型训练用的特征是d维的，例如d维的word embedding，图像的张量，而现在它变成了d撇维的向量，向量中的每一个元素都是非0即1的，我可以称之为d撇维的01向量，也就是binary vector，来表示可解释特征。

![img_38.png](img_38.png)

3.2表示的是，可解释模型本身呢，你想让他复杂，它的可解释性就低了，你想让他简单，它的可解释性就高，但是拟合模型的能力就弱了。所以这里存在一个trade-off权衡。这里的G表示可解释性好的模型，例如决策树这些，g是里面的一个算法。输入的特征是d撇维的01向量，被称之为interpretable components，这些元素存在或者不存在，欧米茄g用来反应这个模型本身的复杂度。这里存在一组trade-off，你想让可解释模型拟合效果好，他就要复杂，但是可解释性就差了，你想让他可解释性好，拟合效果就一般。

![img_39.png](img_39.png)

原模型是输入d维向量得到一个预测结果，我们用派xz来表示样本z距离样本x的距离，近邻的度量指标，我们可以用L来反应模型的局部不可信度，就是拟合的那根直线有多贴近原模型决策边界，欧米茄用来反应可解释模型的复杂度，用来反应这个可解释模型是否容易被人类理解。我们的lime就是要最小化这两项之和，就是既要让它可信，又要让它通俗可理解，又要让它拟合的准又要让它易于被人类理解可解释。它可以用在各种各样的潜在可解释性好的模型中，各种各样的局部不可信的函数中，各种各样的模型复杂度中。在下文中，我们要聚焦这个sparse linear models作为小g，啥叫sparse linear models就是这个模型中很多特征的权重很小或者为0，叫做稀疏的线性模型。

![img_40.png](img_40.png)

首先是待测样本，是d维特征，首先要把d维特征变成d撇维的01向量，然后对这个01向量做扰动，有些0变成1，有些1变成0，做扰动那么待测样本周围就生成了一堆邻域数据，我们把邻域数据恢复成d维向量，然后放到原模型中预测，得到labels，然后用可解释模型小g训练扰动后的d撇维特征，并以原模型预测结果作为标注，然后就可以从可解释模型中看到它学到的特征权重中那些特别重要，对模型预测结果产生较大贡献。并且这里还有一个权重问题，距离待测样本比较近的样本权重比较大，比较远的权重比较小，距离通过pai来反应。

![img_41.png](img_41.png)

接下来是sparse linear explanations，这个距离可以通过这样一个高斯核或者rbf核，以待测样本为圆心画一个圆，以圆里面的样本来计算它的距离。

![img_42.png](img_42.png)

这里的话你会发现，如何去计算这个不可信度，就是把它的距离乘以一个残差，残差就是原模型预测结果减去线性模型预测结果的差的平方，但是这里其实有个问题，距离越远，局部不可信度越大，我们最终是要最小化这个局部不可信度，所以靠近的样本权重比较大。

![img_43.png](img_43.png)

对于文本分类呢，使用特征是可解释的，可解释的特征个数是K，可解释模型的复杂度用这个式子计算，无穷大乘以一个这个东西是不是大于K，如果是的话等于无穷大，不是的话等于0，这个K可以自己设定，可以很大，也可以很小，但为了人类方便理解，所以K在这里用一个常数。对于图像而言，这个欧米茄就是超像素图块的个数。这个方法实际上和数据集的尺寸是无关的，不管多大的数据集都可以用这个方法做分析。并且是非常快的，在笔记本上用scikit learn训练1000颗树组成的随机森林算法，5000个邻域样本只需要3秒就可以计算得到，也不需要GPU或者并行计算。对于图像数据，则需要10分钟左右。这里需要提出，这个时间是作者用它自己的设备去跑的，我们自己在跑的时候可能比这个还要快，毕竟设备的处理效能也在进步。

![img_44.png](img_44.png)

lime中最难的一个步骤就是把原始特征变成可解释特征，这一步需要人类的先验知识，比如图块这里用的是超像素分割算法，但是这个算法并不对应任何语意，还是需要人类自己去设计binary vector，去设计这个可解释特征。第二个就是原始模型本身在高维空间非线性，如果在邻域空间也是非线性的呢。作者这里没有去说如何解决或者论证这个问题，只给出了一个建议，就是不管怎么，先跑一下看看再说，并且可以选择线性模型以外的更好的可解释性模型，这算是未来的工作。所谓纸上得来终觉浅，绝知此事要躬行。

![img_45.png](img_45.png)

看看它的伪代码，选择邻域样本，构建可解释特征x撇，然后把这些邻域样本输入原模型进行预测得到大Z，大Z就是标签，k就是特征，然后训练一个可解释模型，这里是K-Lasso。zi撇作为特征，原模型预测的结果作为标签，训练一个足够拟合原模型的线性模型。

### 4. Submodular Pick for Explaining Models

![img_49.png](img_49.png)

第四部分就是选取有代表性的样本来解释模型，通过有代表性的样本就可以反应模型全局的insights。

![img_50.png](img_50.png)

假如说测试集有X个样本，我们要选择B个样本来代表整个模型的预测结果，该怎么选呢？

![img_51.png](img_51.png)

还是需要看这些样本的可解释，不能只看原始数据和预测结果，并且选出来的这些样本必须多样，还不能有冗余。

![img_52.png](img_52.png)

这里举了个例子。假设这里五个样本，X=5，我们要从五个样本里选出两个有代表性的样本，B=2，那有五个可解释特征对应五个单词吧，对于第二个特征，第二个单词，会发现它在4个样本中出现了，比较有代表性，就从具有第二个特征的样本中选一个出来，第一个红框选出来，f2和f3就覆盖了，我在从这个样本没有覆盖到的，f4和f5中选一个第二个红框的样本出来，这样我就从五个样本中选了两个有代表性样本，能够覆盖到四个特征。也就是你首先得计算每一个特征的代表性，f2有4个灰格，f3f4有两个灰格，那么f2的代表性就比较大，我们可以用Ij来反应出来，Ij等于根号权重求和，这里就是根号4，然后我们就可以从代表性比较高的包含这个特征的样本中去选，不断的去贪婪的尽可能覆盖更多的代表性的特征，就实现了选出有代表性样本的任务。

![img_53.png](img_53.png)

看一下算法，首先获取数据集中每一个样本每一个可解释特征的权重，然后计算每一个特征的代表性Ij，找到使得可解释性特征代表性覆盖最广，求和最大的样本，比如刚才的第二个和第五个样本，他们的特征是互不重合，互不冗余的，而且是足够多样的，那么就用极有限的B尽可能多的覆盖了代表性。我如果已经选了第二个样本了，就不再选第三个样本了，因为都是f2和f3，就冲突和冗余了。

![img_54.png](img_54.png)

特征覆盖度就用c，这个公式计算，例如刚才把第二个样本选了，特征覆盖度就是2，第五个再选了就是4，我们的工作就是要找到使得c最大化的样本集V，可以通过贪婪的方式去迭代的把当前能够使得c边际增加最大的样本选进来，这其实是图覆盖的数学问题，他是NP-hard的问题，它有1-1/e可以收敛到最优点。这样的一种方法被称作submodular pick，也就是sp方法。
