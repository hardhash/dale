> 赛题简介

这是一个计算机视觉OCR方向的比赛，根据图片识别出图片中的关键文字信息。赛题共有两个任务，分别是图片数字识别和图片中文混合文本识别。

> 评价指标

数字识别任务采用指标如下：

$$score1 = \frac{完全识别正确的图片数}{总图片数}$$

文本内容识别采用指标如下：

$$score2 = 1 - CER = \frac{\sum M_{c_i} - I_i}{\sum N_i}$$

其中Mc表示正确识别字数，I表示插入错误字数，N表示参考序列中字符总数。

最终得分为两个任务的平均分：

$$score = 0.5 * score1 + 0.5 * score2$$

> 算法概览

1.    验证集划分策略：比赛训练数据包含噪音数据与正确标注的数据，利用所有噪音数据训练，正确标注数据作为验证。
2.    训练策略：任务1采用sar_resnet31模型，任务2采用satrn-small和sar_resnet31多预训练模型作为特征提取网络，进行微调训练。任务1和2都继承MMOCR的默认参数，修改数据集为中文文本，设置保存最优模型的相关参数。
3.    数据增强：对文本进行了旋转和缩放处理，增强模型鲁棒性。
